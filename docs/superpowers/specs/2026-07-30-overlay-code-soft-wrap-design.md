# 浮层代码块自动换行设计

## 目标

回答浮层中的长代码行按浮层可用宽度自动换行，用户只需上下滚动即可阅读完整代码，
不再需要横向拖动。

本次只修改回答浮层的代码块显示，不改变普通回答文字、代码内容、复制内容、回答滚动、
快捷键、浮层模式或其他功能。

## 当前问题

代码块当前同时使用：

- `white-space: pre`：完整保留空格和换行，但禁止自动折行。
- `overflow-x: auto`：内容超宽时创建横向滚动区域。

因此，只要一行代码超过浮层宽度，右侧内容就必须通过横向滚动查看。

## 显示方案

代码块改为视觉软换行：

- 使用 `white-space: pre-wrap`，保留源码中的空格、缩进和原始换行，同时允许超长行折行。
- 使用 `overflow-wrap: anywhere`，让超长网址、字符串或连续字符也能在浮层内折行。
- 禁止代码块产生横向滚动条。
- 短于可用宽度的代码行保持原有显示，不产生额外换行。

这些换行只存在于浏览器排版层。React 仍直接渲染原始 `seg.content`，不向代码字符串
插入换行符，因此复制、重试、历史记录和模型返回内容均不改变。

## 可读性取舍

软换行会让极长的一行代码显示成多行，但这是视觉折行，不表示源码中新增了语句换行。
相比缩小字体或放大整个浮层，软换行能保持现有字号并避免遮挡更多屏幕，适合窄浮层阅读。

原始缩进、空格和真正的换行仍被保留。只有超出浮层宽度的部分折到下一视觉行。

## 不修改的范围

- 不修改 Markdown 分段与转义逻辑。
- 不修改代码文本或复制行为。
- 不增加横向滚动快捷键或换行开关。
- 不自动改变浮层宽度和字号。
- 不修改主窗口、截图、录音、回答滚动或快捷键。

## 验证

- 组件测试确认代码块使用 `pre-wrap`、允许连续字符折行，并禁用横向滚动。
- 测试确认渲染的代码文本仍与输入字符串完全一致。
- 普通 Markdown 文本渲染保持不变。
- 运行完整测试、代码检查、类型检查和生产构建。
